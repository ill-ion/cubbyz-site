# Cubbyz Website

Next.js App Router project prepared for Vercel.

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy to Vercel

Import this folder/repository into Vercel. Vercel detects Next.js automatically.

- Framework preset: Next.js
- Build command: automatic
- Output directory: default
- Install command: automatic

After deployment, add `cubbyz.com` under **Project Settings → Domains**.

The Telegram product CTA is intentionally not wired yet because the product is coming soon.
